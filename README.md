# TV96 Live

TV96 Live is a responsive football platform built to provide users with football fixtures, league standings, sports news, and match information through a clean and mobile-friendly interface.

## Features

- Responsive design for desktop and mobile devices
- Football fixtures and match information
- League standings
- Sports news and article pages
- Third-party API integration
- Dynamic JavaScript content
- Dark and light interface support
- Production deployment with a custom domain

## Technologies

- HTML5
- CSS3
- JavaScript
- REST APIs
- Git & GitHub
- Vercel

## What I Worked On

I designed, developed, and maintained the front-end of the platform, including responsive layouts, dynamic content, API integrations, debugging, deployment, and ongoing website improvements.

The project has been continuously developed and improved based on usability, performance, and content requirements.
